# 🌿 LifeOS

[English Version / Английская версия](README.md)

**LifeOS** — это приватный, полностью автономный персональный командный центр (offline-first). Он объединяет в едином интерфейсе отслеживание привычек, ведение финансов, журнал тренировок и велопоездок, структурирование мыслей и интерактивную визуализацию социальных связей.

Все данные хранятся **локально на вашем устройстве** (в IndexedDB и localStorage), гарантируя 100% конфиденциальность и полный контроль над вашей личной информацией.

---

## 🎯 Что такое LifeOS и для кого он полезен?

LifeOS создан для людей, которые хотят упорядочить ключевые сферы своей жизни в единой системе координат, не доверяя свои личные данные коммерческим облачным сервисам.

### 👥 Проект полезен для:
* **Сторонников приватности (Privacy Enthusiasts):** Для всех, кто хочет вести дневник, учитывать финансы и привычки без отправки данных на серверы третьих лиц.
* **Людей, занимающихся саморефлексией:** Для тех, кто строит цифровую базу знаний по методу Zettelkasten и структурирует свои мысли.
* **Активных коммуникаторов:** Для людей с широким кругом контактов, желающих вовремя диагностировать угасание связей и оценивать взаимность общения.
* **Велосипедистов и спортсменов:** Для любителей велоспорта, которым нужен удобный журнал поездок, планировщик маршрутов и учет интервалов технического обслуживания компонентов велосипеда.
* **Рациональных финансистов:** Для тех, кому нужен простой учет доходов/расходов и напоминания о регулярных счетах без привязки реальных банковских аккаунтов.

## 📦 Что внутри проекта? (Модули)

Интерфейс LifeOS разделен на шесть ключевых модулей, каждый из которых отвечает за свою сферу:

### 1. 🎛️ Главный хаб (Hub)
Единый рабочий стол приложения. Здесь собрана сводка на день: задачи, ближайшие платежи, активные привычки, последние записи в дневнике и общая статистика.

### 2. 🤝 Граф связей (Social Graph)
Интерактивный граф отношений на физическом движке (работает в фоновом Web Worker):
* **Диагностика угасания:** Показывает «температуру» отношений на основе давности последнего контакта.
* **Оценка взаимности (Reciprocity):** Вычисляет коэффициенты энергообмена и баланса контактов.
* **Тегирование и заметки:** Возможность группировать людей по тегам и фиксировать детали встреч.

### 3. 💳 Финансы (Finance)
Простая домашняя бухгалтерия.
* **Категории транзакций:** Удобный учет поступлений и расходов по категориям.
* **Напоминания о счетах:** Контроль регулярных платежей с напоминанием за несколько дней.
* **Экспорт в CSV:** Выгрузка реестра транзакций для анализа в Excel или Google Таблицах.

### 4. 🚴 Велосипед (Cycling)
Журнал поездок и сервисная книжка для велосипедистов.
* **Журнал заездов:** Запись дистанции, времени, набора высоты, пульса и мощности.
* **Планировщик маршрутов:** Создание маршрутов, указание точек (waypoints) и уровней сложности.
* **Техническое обслуживание (ТО):** Контроль износа деталей и планирование сервиса (ремонт, чистка, замена) на основе пробега и времени эксплуатации.

### 5. 🧘 Рефлексия (Reflection)
Инструменты для осознанности, работы с информацией и привычками.
* **Дневник:** Записи мыслей с оценкой настроения дня и тегами.
* **База знаний (Wiki):** Личная база знаний по системе Zettelkasten для связывания идей.
* **Привычки:** Трекер ежедневных привычек с подсчетом серий по различным категориям.
* **Тренировки:** Фиксация силовых, кардио- и йога-сессий.
* **Расписание:** Блочное планирование дня.

### 6. 📊 Аналитика (Analytics)
Кросс-модульный центр анализа. Объединяет данные из всех разделов для предоставления рекомендаций и автоматического расчета индекса усталости (на основе тренировок, привычек и сна).

## 🛠️ Технологический стек

* **React 19 + TypeScript 6** — Строгая типизация компонентов.
* **Vite 8** — Сверхбыстрая сборка и локальный сервер.
* **React Router 7** — Декларативная маршрутизация и плавная анимация переходов.
* **Локальное хранилище (Offline-First)** — Данные пишутся в транзакционную базу **IndexedDB** (библиотека `idb`) с резервным автосохранением в **localStorage** (с дебаунсом 2.5 секунды).
* **Zod** — Валидация структуры базы данных при миграциях на стороне клиента.
* **Полная приватность** — Отсутствие внешних API, облачных баз и аналитики.

## 🎨 Темы оформления и оптимизация производительности

В приложении доступны 4 темы оформления:
1. **MindVey** — Стеклянный фиолетовый неон (Glassmorphic).
2. **Cyclist** — Спортивный оранжево-темный стиль.
3. **Reflect** — Минималистичная светлая тема.
4. **Slate** — Нейтральная темная тема.

### Режимы:
* **Ручной** — Фиксированный выбор темы.
* **Адаптивный** — Тема меняется автоматически в зависимости от выбранного модуля.
* **Системный** — Подстраивается под светлый/темный режим вашей ОС.

### ⚡ Режим производительности (Для старых ПК и Windows)
Если при переходе между вкладками интерфейс лагает из-за обилия эффектов размытия и анимированного фона:
1. Откройте **Настройки** (шестеренка в правом верхнем углу или `Ctrl + ,`).
2. В пункте **Режим графики** выберите `Производительность (Без размытия и живых обоев)`.
3. В пункте **Анимация интерфейса** выберите `Отключена` (или выберите `Включена (принудительно)`, если Windows блокирует анимацию в вашем браузере).

## 🚀 Быстрый старт

### Требования
Убедитесь, что у вас установлена платформа [Node.js](https://nodejs.org/) (рекомендуется v18+).

### Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/m0rvey/lifeos.git
   cd lifeos
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите локальный сервер разработчика:
   ```bash
   npm run dev
   ```
4. Сборка для продакшна:
   ```bash
   npm run build
   ```
