## 📌 О проекте

**LifeOS** — это персональный командный центр, работающий по принципу **Offline-First**. Приложение объединяет ключевые сферы жизни в единый контур: от ежедневных задач и стриков привычек до домашней бухгалтерии, велотренировок с гаражом велосипедов, графа связей Zettelkasten и карты социального окружения.

> **🔒 100% Приватность по умолчанию:** Все данные хранятся исключительно в браузере пользователя (IndexedDB + локальный fallback). Никаких внешних серверов, облачных баз данных, трекеров и телеметрии.

## ✨ Ключевые модули и возможности

### 1. 🎛️ Главный хаб и матрица задач (Hub & Tasks)
* **Интеллектуальная матрица Эйзенхауэра:** Распределение задач по 4 квадрантам на основе срочности и эмоциональной важности (*Сделать срочно*, *Запланировать*, *Быстро/Делегировать*, *Бэклог*).
* **Сводка дня:** Текущий статус когнитивной нагрузки, активные привычки, ближайшие счета и быстрый доступ ко всем разделам.
* **Трекер выполнения:** Фильтрация по статусам, тегирование, дедлайны и заметки.

### 2. 🧠 База знаний и Zettelkasten (Reflect & Knowledge)
* **Интерактивный 2D-граф знаний:** Визуализация связей между заметками по общим тегам и тематическим категориям с поддержкой зума, панорамирования и карточки предпросмотра.
* **Obsidian / Notion Ready:** Экспорт дневника и базы знаний в чистый Markdown (`.md`) с Frontmatter-метаданными в один клик.
* **Дневник рефлексии:** Фиксация мыслей, теги и оценка настроения.
* **Трекер привычек:** Учет серий (стриков) с корректной календарной обработкой часовых поясов.
* **Журнал тренировок:** Логирование силовых, беговых и восстановительных тренировок.

### 3. 🚴 Велоспорт и Гараж (Cycling & Garage)
* **Мульти-гараж:** Раздельный учет пробега, количества выездов и истории ТО для каждого велосипеда (шоссейный, грэвел, МТБ, городской).
* **Журнал заездов:** Фиксация расстояния, набора высоты, времени, средней и максимальной скорости, мощности (Вт) и пульса (bpm).
* **Сервисная книжка (ТО):** Контроль износа компонентов (цепь, кассета, покрышки, тормоза) и планирование обслуживания.
* **Планировщик маршрутов:** Каталог треков с путевыми точками и оценкой сложности.

### 4. 💳 Капитал и Бюджетирование (Finance & Budgets)
* **Контроль бюджетов:** Автоматический подсчет расходов текущего месяца по категориям с визуальным индикатором лимита.
* **Цели накопления:** Трекер сбережений с динамическими шкалами прогресса.
* **Календарь регулярных платежей:** Напоминания о подписках, счетах и обязательствах.
* **Аналитический журнал:** Фильтрация операций и экспорт в локальный CSV.

### 5. 🤝 Социальный граф (Social Graph)
* **Физическая модель связей:** Интерактивная 2D-симуляция социального окружения (работает в фоновом Web Worker без нагрузки на UI).
* **Диагностика угасания:** Индикация «температуры» контактов на основе давности последнего взаимодействия.
* **Оценка взаимности (Reciprocity):** Анализ баланса инициативы и энергообмена в общении.

### 6. 📊 Кросс-модульная аналитика (Analytics)
* Радарная диаграмма баланса 5 сфер жизни: *Когнитивная*, *Социальная*, *Финансовая*, *Физическая*, *Ментальная*.
* Расчет интегрального индекса усталости (Fatigue Score).

## 🏛️ Архитектура и хранение данных

```
┌─────────────────────────────────────────────────────────────┐
│                       React 19 UI                           │
│  (Hub / Tasks / Finance / Cycling / Reflection / Social)    │
└──────────────────────────────┬──────────────────────────────┘
                               │
                      DataContext & Reducer
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
   ┌─────────────────┐                  ┌──────────────────┐
   │ IndexedDB (idb) │ ──[Async Sync]── │  localStorage    │
   │ (Primary Store) │                  │ (Atomic Fallback)│
   └─────────────────┘                  └──────────────────┘
            │
            ▼
    Zod Validation & Migrations Engine
```

* **Транзакционность:** Все операции пишутся в IndexedDB через асинхронный движок с защитой от сбоев.
* **Схема и миграции:** Автоматическая валидация версий данных через схемы **Zod**.
* **Резервное копирование:** Мгновенный экспорт и импорт полного JSON-снапшота системы.

## 🎨 Темы оформления

| Тема | Описание |
| :--- | :--- |
| **MindVey** | Темная неоновая тема с акцентным фиолетовым свечением и стеклянным эффектом |
| **Cyclist** | Контрастная спортивная тема с оранжевыми индикаторами |
| **Reflect** | Минималистичный чистый светлый стиль |
| **Slate** | Сдержанная нейтральная темная палитра |

> Поддерживается **Адаптивный режим** (автоматическая смена темы при переходе между разделами) и **Режим высокой производительности** (отключение размытия для слабых устройств).

## 🚀 Быстрый старт

### Требования
* **Node.js** `>= 18.0.0`
* **npm** `>= 9.0.0`

### Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/m0rvey/lifeos.git
cd lifeos

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev

# 4. Запустить тесты
npm run test

# 5. Собрать production-бандл
npm run build
```
