## 📌 О проекте

**LifeOS** — это персональный командный центр, работающий по принципу **Offline-First**. Приложение объединяет ключевые сферы жизни в единый контур: от ежедневных задач и стриков привычек до домашней бухгалтерии, велотренировок с гаражом велосипедов, графа связей Zettelkasten, расписания недели, музея воспоминаний и карты социального окружения.

> **🔒 100% Приватность по умолчанию:** Все данные хранятся исключительно в браузере пользователя (IndexedDB + локальный fallback). Никаких внешних серверов, облачных баз данных, трекеров и телеметрии. Ваши данные принадлежат только вам.

## ✨ Ключевые модули и возможности

### 1. 🎛️ Главный хаб и матрица задач (Hub & Tasks)
* **Интеллектуальная матрица Эйзенхауэра:** Распределение задач по 4 квадрантам на основе срочности и эмоциональной важности (*Сделать срочно*, *Запланировать*, *Быстро / Делегировать*, *Бэклог*).
* **Сводка дня:** Текущий статус когнитивной нагрузки, активные привычки, ближайшие счета, свежие заметки и быстрый запуск действий.
* **Трекер выполнения:** Фильтрация по статусам, тегирование, дедлайны, заметки и переключение чекбоксов.

### 2. 🧠 База знаний, рефлексия и привычки (Reflect & Knowledge)
* **Интерактивный 2D-граф знаний:** Визуализация связей между заметками по общим тегам и тематическим категориям с поддержкой зума, панорамирования и карточки предпросмотра.
* **Obsidian / Notion Ready:** Экспорт базы знаний и заметок в чистый Markdown (`.md`) с Frontmatter-метаданными в один клик.
* **Дневник рефлексии:** Фиксация мыслей, теги и оценка настроения (шкала 1–5).
* **Трекер привычек:** Учет непрерывных серий (стриков) с календарной нормализацией часовых поясов.
* **Журнал тренировок:** Логирование силовых, беговых, кардио и восстановительных тренировок с указанием мышечных групп и интенсивности.
* **Недельное расписание (Routine & Schedule):** Планировщик регулярного недельного графика (Пн–Вс) с тайм-слотами и цветовой категоризацией.
* **Цифровой музей (Museum of Memories & Quotes):** Коллекция памятных цитат, жизненных озарений, артефактов и достижений.

### 3. 🚴 Велоспорт и Гараж (Cycling & Garage)
* **Мульти-гараж:** Раздельный учет пробега, количества выездов и истории ТО для каждого велосипеда (шоссе, грэвел, МТБ, городской).
* **Журнал заездов (Телеметрия):** Фиксация дистанции, набора высоты, времени, средней и максимальной скорости, мощности (Вт), пульса (bpm) и восприятия нагрузки (RPE).
* **Сервисная книжка (ТО):** Контроль износа компонентов (цепь, кассета, покрышки, тормозные колодки) и планирование сервисных интервалов.
* **Планировщик маршрутов:** Каталог треков с путевыми точками, типом покрытия (асфальт, гравий, трейл) и оценкой сложности.

### 4. 💳 Капитал и Бюджетирование (Finance & Budgets)
* **Контроль бюджетов:** Автоматический подсчет расходов текущего месяца по категориям с визуальным индикатором лимита.
* **Цели накопления:** Трекер сбережений с динамическими шкалами прогресса и сроками достижения.
* **Календарь регулярных платежей:** Напоминания о подписках, счетах и обязательствах со статусом оплаты.
* **Аналитический журнал:** Фильтрация операций, учет доходов/расходов и экспорт в локальный CSV.

### 5. 🤝 Социальный граф (Social Graph & CRM)
* **Физическая модель связей:** Интерактивная 2D-симуляция социального окружения на базе force-directed физики, выполняемая в фоновом **Web Worker** без задержек основного UI.
* **Диагностика угасания (Decay Engine):** Индикация «температуры» контактов на основе дней, прошедших с момента последнего общения.
* **Оценка взаимности (Reciprocity):** Анализ баланса инициативы и энергообмена в общении.
* **Карточки контактов:** История встреч, заметки, дни рождения, круги близости (Inner Circle, Close Friends, Network).

### 6. 📊 Кросс-модульная аналитика (Analytics & Fatigue Engine)
* **Радарная диаграмма баланса 5 сфер жизни:** *Когнитивная*, *Социальная*, *Финансовая*, *Физическая*, *Ментальная*.
* **Интегральный индекс усталости (Fatigue Score):** Математическая модель расчета нагрузки на основе просроченных задач, физических тренировок, заездов и маркеров восстановления.

## 🏛️ Архитектура и хранение данных

```
┌─────────────────────────────────────────────────────────────────────────┐
│                               React 19 UI                               │
│        (Hub / Tasks / Reflect / Finance / Cycling / Social / Stats)     │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                 ┌───────────────────┴───────────────────┐
                 ▼                                       ▼
       AppContext (UI / Theme)               DataContext (State + History)
                 │                                       │
                 ▼                                       ▼
        TagRegistry (Tags Index)             dataHistory (50 Undo/Redo)
                                                         │
                                                         ▼
                                                idbEngine (IndexedDB v10)
                                            ┌────┴──────────────────────┐
                                            ▼                           ▼
                                  IndexedDB Stores             Atomic localStorage
                                  (Primary Engine)             (Resilient Fallback)
                                            │
                                            ▼
                                  Zod Schema Validation &
                                  Versioned Migrations Engine
```

* **Транзакционность:** Все операции пишутся в IndexedDB (17 специализированных хранилищ) через асинхронный движок с защитой от сбоев.
* **Схема и миграции:** Автоматическая валидация версий данных (v1 → v10) через строгие схемы **Zod**.
* **Резервное копирование:** Мгновенный экспорт и импорт полного JSON-снапшота системы.
* **История изменений:** Встроенный стек истории на 50 шагов (Undo / Redo).

## 🎨 Темы оформления

| Тема | Описание |
| :--- | :--- |
| **MindVey** | Темная неоновая тема с акцентным фиолетовым свечением и стеклянным эффектом (Glassmorphism) |
| **Cyclist** | Контрастная спортивная темная тема с яркими оранжевыми акцентами |
| **Reflect** | Минималистичный чистый светлый стиль для спокойного чтения и письма |
| **Slate** | Сдержанная нейтральная темная палитра для максимальной концентрации |

> **Дополнительные режимы:**
> * **Адаптивный режим:** Автоматическая смена темы при переходе между функциональными разделами.
> * **Режим высокой производительности:** Отключение эффектов размытия (backdrop-filter) для максимального FPS на слабых устройствах.

## 🚀 Быстрый старт

### Требования
* **Node.js** `>= 18.0.0`
* **npm** `>= 9.0.0`

### Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/m0rvey/lifeos.git
cd lifeos

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev

# 4. Собрать production-бандл
npm run build
```
