# 🌿 LifeOS

[English Version / Английская версия](README_EN.md)

**LifeOS** — персональный автономный командный центр (offline-first). Приложение объединяет в едином пространстве управление задачами и привычками, домашнюю бухгалтерию, журнал велотренировок и обслуживания велосипеда, дневник с базой знаний Zettelkasten и визуализацию социального окружения.

Все данные хранятся **исключительно локально на вашем устройстве** (в IndexedDB и localStorage) без сторонних серверов и облачной телеметрии.

---

## 📦 Модули системы

### 1. 🎛️ Главный хаб и задачи (Hub & Tasks)
* **Сводка дня:** Текущий статус, активные привычки, ближайшие платежи и расчет индекса усталости.
* **Матрица Эйзенхауэра:** Интеллектуальная доска задач с разделением на 4 квадранта по срочности и важности (*Сделать срочно*, *Запланировать*, *Делегировать/Быстро*, *Отложить/Бэклог*).
* **Список задач:** Фильтрация, теги, дедлайны и отметка выполнения.

### 2. 🤝 Социальный граф (Social Graph)
* **Интерактивная карта связей:** 2D-граф отношений на физическом движке в фоновом Web Worker.
* **Диагностика контактов:** Отслеживание давности общения и автоматическое предупреждение об угасании связей.
* **Баланс общения:** Оценка энергии, резонанса и взаимности по каждому контакту.

### 3. 💳 Финансы (Finance)
* **Учет операций:** Удобный журнал доходов и расходов по категориям.
* **Месячные бюджеты:** Контроль лимитов по статьям расходов с прогресс-баром.
* **Цели накопления:** Трекер сбережений с визуализацией прогресса.
* **Календарь счетов:** Напоминания о регулярных платежах.
* **Экспорт:** Выгрузка реестра операций в CSV.

### 4. 🚴 Велоспорт (Cycling)
* **Журнал тренировок:** Фиксация дистанции, времени, набора высоты, средней и максимальной скорости, пульса и мощности.
* **Гараж велосипедов:** Раздельный учет пробега и статистики по каждому велосипеду (шоссейный, грэвел, МТБ, городской).
* **Планировщик маршрутов:** Сохранение маршрутов с путевыми точками (waypoints) и сложностью.
* **Техническое обслуживание (ТО):** Контроль износа деталей и планирование сервисных работ.

### 5. 🧘 Рефлексия (Reflection)
* **Личный дневник:** Записи мыслей с оценкой настроения дня и тегами.
* **База знаний (Wiki / Zettelkasten):** Структурирование заметок, статей и книг.
* **Интерактивный граф знаний:** 2D-визуализация связей между заметками по общим тегам и категориям.
* **Экспорт в Markdown:** Выгрузка дневника и заметок в структурированные `.md` файлы для Obsidian и Notion.
* **Трекер привычек:** Ежедневный трекинг серий (стриков) с учетом локального часового пояса.
* **Журнал тренировок:** Логирование силовых, беговых и йога-сессий.
* **Расписание:** Блочное планирование распорядка дня.

### 6. 📊 Аналитика (Analytics)
* Сквозной анализ баланса сфер жизни (когнитивный, социальный, финансовый, физический, ментальный).
* Автоматические рекомендации по снижению нагрузки и восстановлению ресурсов.

## 🛠️ Технологический стек

* **Frontend:** React 19, TypeScript, React Router 7, Vite.
* **Хранилище:** IndexedDB (`idb`) + fallback в localStorage (offline-first).
* **Валидация:** Zod.
* **Стилизация:** Чистый CSS с переменными тем, адаптивностью и поддержкой режима высокой производительности.
* **Тестирование:** Vitest, Testing Library.

---

## 🎨 Темы оформления

В приложении доступно 4 темы интерфейса:
1. **MindVey** — Темный неоновый стиль (Glassmorphism).
2. **Cyclist** — Спортивный оранжево-темный стиль.
3. **Reflect** — Минималистичная светлая тема.
4. **Slate** — Сдержанная нейтральная темная тема.

## 🚀 Установка и запуск

### Требования
* [Node.js](https://nodejs.org/) версии 18 или выше.

### Команды
```bash
# Клонирование репозитория
git clone https://github.com/m0rvey/lifeos.git
cd lifeos

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка проекта
npm run build

# Запуск тестов
npm run test
```
