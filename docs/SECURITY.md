# 🛡️ Security & Privacy Policy — LifeOS

## 🔒 Security & Privacy Architecture

**LifeOS** is built on a strict **Local-First & Offline-Always** architecture:
- **Zero External Telemetry:** The application contains zero tracking scripts, analytics SDKs, or cloud telemetry.
- **In-Browser Persistence:** All personal data is stored exclusively on the client machine using **IndexedDB**.
- **Data Integrity:** Runtime schema validation on all database operations using **Zod**.

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or privacy concern in **LifeOS**, please report it responsibly:
- Open an Issue on GitHub with the `security` label, or
- Report privately via the **Security > Report a vulnerability** tab on the GitHub repository.

All reports will be addressed promptly.
